# 后端基础对象（建议最小集合）

> 目标：提供后端“基础对象文件”，用于统一地图模块的核心业务对象定义。
> 范围：Route / Point / Fence + 通用坐标类型（不含渲染聚合 DTO）。

## 基础业务对象
- Route（路线）
- Point（点位）
- Fence（电子围栏）

## 通用类型
- LngLat（经纬度坐标独享，lng=经度，lat=纬度）
- Bound（外接矩形范围，sw=西南角，ne=东北角）
- Polyline（路径点 / 轨迹点 / 帖路网点）
- ISODateTime （日期字符串）
- ISODate（日期时间字符串）

## 推荐对象结构

### 通用类型
```ts
export type ISODateTime = string; // ISO 8601，例如：2026-02-09T10:00:00Z
export type ISODate = string;     // YYYY-MM-DD

export interface LngLat {
  lng: number;
  lat: number;
}

export interface Bound {
  sw: LngLat;
  ne: LngLat;
}

export type Polyline = LngLat[] | string;
```

### Fence（电子围栏）
```ts
export enum FenceType {
  CIRCLE = "CIRCLE",
  POLYGON = "POLYGON",
}

export enum FenceStatus {
  ENABLED = "ENABLED",
  DISABLED = "DISABLED",
}

export interface FenceDTO {
  id: string;
  name: string;
  type: FenceType;
  status: FenceStatus;

  center?: LngLat | null;   // CIRCLE
  radius?: number | null;   // CIRCLE
  points?: LngLat[] | null; // POLYGON

  bound?: Bound | null;
  remark?: string | null;
  createdAt?: ISODateTime;
  updatedAt?: ISODateTime;
}
```

### Point（点位）
```ts
export interface PointDTO {
  id: string;
  name: string;
  location: LngLat;
  address?: string | null;
  fenceIds?: string[] | null;
  remark?: string | null;
  createdAt?: ISODateTime;
  updatedAt?: ISODateTime;
}
```

### Route（路线）
```ts
export enum TravelMode {
  BICYCLING = "BICYCLING",
}

export interface RoutePointRef {
  pointId: string;
  order: number;
  name?: string;
  location?: LngLat;
  fenceIds?: string[];
}

export interface RouteDTO {
  id: string;
  name: string;
  travelMode: TravelMode;
  points: RoutePointRef[];
  remark?: string | null;
  createdAt?: ISODateTime;
  updatedAt?: ISODateTime;
}
```

## 不属于基础对象的部分（建议不放在基础对象文件）
- RouteRenderDTO（聚合渲染 DTO）
- RoutePreviewDTO / RouteDetailDTO
- RecommendOrder* 相关结构
- PunchRecord* / Export* 等业务扩展
